# SIST — M1A2 Abrams, процедурный WebGL2

Интерактивная 3D-сцена с танком M1A2 Abrams (CARC Tan 686A). Вся геометрия генерируется кодом,
рендер — чистый WebGL2 без Three.js и других библиотек.

## Запуск

```bash
node tools/serve.mjs 8080      # http://localhost:8080
```

Управление: ЛКМ — вращение, ПКМ / Shift — сдвиг, колесо — масштаб, клавиши 1–6 — ракурсы,
ползунки — поворот башни и угол возвышения ствола.

## Контрольные скриншоты

```bash
npm install                    # playwright-core + @sparticuz/chromium (только для скриншотов)
node tools/shoot.mjs http://127.0.0.1:8080/ shots
```

Скрипт снимает профиль, вид сверху, вид спереди и 3/4 на башню в `shots/`.
Свой браузер можно указать через `CHROMIUM_PATH`.

## Устройство

- `js/mesh.js` — конструктор геометрии: выпуклые многогранники из полупространств, фаски, тела вращения, трубы.
- `js/abrams.js` — модель: корпус, ходовая часть, башня, пушка.
- `js/renderer.js` — PBR-шейдинг, мягкие тени (PCSS), карта затенения сверху, SSAO, суперсэмплинг, ACES.
- `js/main.js` — камера, ракурсы, интерфейс.
