# SIST

Интерактивный 3D-аквариум в одном HTML-файле — [`aquarium.html`](aquarium.html).

Three.js, все шейдеры, рыбы, растения и декор встроены прямо в файл, внешние
ресурсы не нужны — достаточно открыть страницу в браузере.

## Управление

- **Перетаскивание мышью** — вращение камеры
- **Колесо мыши / пинч** — масштаб
- **Клик по воде** — пузыри, **клик по рыбке** — она уплывёт
- **Покормить** — корм падает на дно, рыбки подплывают к нему
- **Добавить рыбку** — до 20 рыб в аквариуме
- **Пузыри** и **Автоповорот** — переключатели сцены
- Клавиши: `Space`/`F` — корм, `A` — новая рыбка, `B` — пузыри, `R` — автоповорот

Сцена процедурная: стеклянный аквариум с каустикой, песчаным дном, водорослями,
кораллами, стайкой рыб с собственной моделью плавания, пузырьковыми колоннами и
лучами света. Камера плавно вращается сама, когда её не трогают.
